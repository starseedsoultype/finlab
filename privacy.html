Политика конфиденциальности

ФИНЛАБ · Дата: 9 июня 2025 г.

1. Кто обрабатывает данные

Попова Олеся Ринатовна, самозанятая. Контакт: Telegram @alexandra_source

2. Какие данные собираются

ДанныеОткудаЗачем
Telegram ID / VK IDTelegram / VKИдентификация участника ФИНЛАБ
Имя или usernameTelegram / VKОбращение, поддержка
Ответы на заданияБотПроверка выполнения, обратная связь
Дата и сумма оплатыProdamus / StripeПодтверждение участия

Мы не собираем: паспортные данные, номер телефона, адрес, геолокацию, данные банковской карты.

3. На каком основании

  • Исполнение договора (ст. 6(1)(b) GDPR; ст. 6 ФЗ-152) — для обеспечения работы ФИНЛАБ
  • Согласие — для отправки напоминаний через 100 дней (можно отозвать, написав боту /unsubscribe)

4. Кому передаются данные

OpenAI (США) — ответы на задания передаются для автоматической проверки. Данные передаются без имени участника ФИНЛАБ и не используются для обучения моделей (условие API).

Supabase (США) — хранение базы данных участников. Данные защищены шифрованием в покое и при передаче.

Prodamus / Stripe — платёжные данные. Обрабатываются этими сервисами согласно их собственным политикам конфиденциальности.

Третьим лицам в маркетинговых целях данные не передаются.

5. Сколько хранятся данные

Данные об участии в ФИНЛАБ: 1 год с даты завершения участия. После этого срока данные удаляются из базы по запросу или автоматически.

Чтобы запросить удаление своих данных раньше срока — напишите @alexandra_source или отправьте боту /delete_my_data

6. Ваши права

  • Запросить копию своих данных
  • Исправить неточности
  • Потребовать удаления данных
  • Отозвать согласие на рассылки

Для реализации любого из прав — Telegram @alexandra_source. Ответ в течение 30 дней.

7. Безопасность

Данные хранятся на серверах Supabase с шифрованием. Доступ к базе имеет только бот (сервисный ключ) и автор ФИНЛАБ (через защищённый аккаунт).

8. Дети

ФИНЛАБ предназначен для лиц старше 18 лет. Если вам нет 18 — не используйте бот.

9. Изменения политики

При существенных изменениях — уведомление через бот. Актуальная версия всегда на этой странице.
